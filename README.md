# فروشگاه اینترنتی — پروژهٔ تمرینی React

پیاده‌سازی رابط کاربری یک پلتفرم فروشگاه اینترنتی با
معماری کامپوننت‌محور.

> ⚠️ پروژهٔ **شخصی و آموزشی** — بدون هیچ وابستگی به
> شرکت دیجی‌کالا.

## ✨ امکانات

- 🛍 نمایش محصولات با دسته‌بندی
- 🎠 اسلایدر تبلیغاتی و بنرها
- 🏷 بخش تخفیف‌ها و پیشنهاد ویژه
- 📱 طراحی واکنش‌گرا (Responsive)
- 🧩 معماری کامپوننت‌محور با ۹ ماژول مستقل

## 🛠 تکنولوژی

| بخش | ابزار |
|---|---|
| Frontend | React (JavaScript) |
| Styling | Tailwind CSS · PostCSS |
| Build | Create React App |

## 🏗 ساختار پروژه

```
src/
├── Navbar/          نوار ناوبری
├── Slider/          اسلایدر اصلی
├── Category/        دسته‌بندی محصولات
├── Products/        لیست و کارت محصول
├── Discount/        بخش تخفیف‌ها
├── Advertisement/   بنرهای تبلیغاتی
├── Bar/             نوار اطلاعات
├── Read/            بخش مطالب
└── Footer/          فوتر
```

## 🚀 راه‌اندازی

```bash
git clone https://github.com/MiadYazdi/digikala.git
cd digikala
npm install
npm start
```

سپس `http://localhost:3000` را باز کنید.
